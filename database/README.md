# پشتیبان دیتابیس

این پوشه برای نگهداری نسخه‌های پشتیبان است.

**دریافت نسخه به‌روز:** وارد سایت شوید ← مدیریت ← تنظیمات ← بخش «نسخه پشتیبان»:

- **ساختار دیتابیس (schema.sql):** همه جدول‌ها، قوانین امنیتی، محاسبه قیمت، پورسانت، ضمانت و فضاهای فایل. برای ساخت دوباره سایت روی یک پروژه تازه Supabase، محتوای آن را در SQL Editor پروژه جدید اجرا کنید.
- **همه اطلاعات (data.json):** همه رکوردهای فروشگاه (محصولات، سفارش‌ها، کاربران، کیف پول، همکاران و …).

فایل‌های دانلودشده را می‌توانید همین‌جا (Add file ← Upload files) آپلود کنید.

> نکته: data.json شامل اطلاعات شخصی مشتری‌ها و کدهای انبار است. چون این مخزن عمومی است، **data.json را اینجا آپلود نکنید** و جای خصوصی (مثلاً گوگل‌درایو) نگه دارید. schema.sql اطلاعات شخصی ندارد و گذاشتنش اینجا مشکلی ندارد.
